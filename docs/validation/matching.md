## Подбор: доля релевантных в топе

Синтетика: 2400 кандидатов (6 специализаций × 400), 120 потребностей для подбора весов и 120 отложенных для оценки. У каждого кандидата есть скрытая истина (реальные навыки и способность θ) и наблюдаемый профиль: заявленные навыки с приукрашиванием (~18 % лишних), пропуски (~15 % реальных не заявлены), категория из теста с ошибкой измерения σ = 0.3, подтверждённые тестом навыки (~45 % реальных), ФСП у ~18 %. Релевантность (0–3) считается по истине функцией, отличной от скоринга: реальное покрытие обязательных навыков, попадание реальной θ в диапазон грейда, совместимость формата и зарплаты. Релевантным считается оценка ≥ 2.
